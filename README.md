## 🛠️ Getting Started

```bash
# Clone the repository
git clone https://github.com/Digambar20/PortDK.git

# Navigate to frontend
cd PortDK/frontend

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
